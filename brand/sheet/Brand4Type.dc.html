Two typefaces, one scale

The same pair as the rest of the ZIO family. Space Grotesk carries headings, body and the wordmark. JetBrains Mono carries code, type names and small labels. Both are open source and served from Google Fonts.

4.3
Code
JetBrains Mono at 15 to 16 px, line height 1.7. Keywords take Deep strand on light and the lifted violet on dark. Type names take amber, the one warm colour, used only inside code, so the reader's eye finds the types first.
Light mode
// one description, many codecs
final case class Person(name: String, age: Int)
 
object Person {
  implicit val schema: Schema[Person] = DeriveSchema.gen
  val protobuf: BinaryCodec[Person] =
    ProtobufCodec.protobufCodec
}

4.4
Rules
Use
Sentence case. Short headings. One Display line per layout.
Use
600 for the wordmark and buttons, 700 for headings.
Use
Mono for type names in running text: Schema[A], DynamicValue.
Avoid
A third typeface, or a serif display.
Avoid
Base light for any text on white: it is 2.1 : 1.
Avoid
Weights under 400. They thin out at small sizes.
