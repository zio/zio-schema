Sixteen pixels, many places

A favicon test bench. The icon is shown at real size in the places it has to work: a crowded tab strip, a pinned tab, a full window with a bookmarks bar, a history menu and a phone home screen. Neighbouring tabs use neutral grey placeholders, so only the ZIO Schema icon carries colour.
